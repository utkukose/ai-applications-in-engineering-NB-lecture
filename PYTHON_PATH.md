# The Python path

The course teaches Python step by step alongside the engineering content. Every week ends its lecture with a Python step that explains one group of fundamentals with the week's own example, shows each code block together with its real output and closes with a quick check. The hands-on part of the weekly notebook opens with the same step as runnable cells and short exercises with immediate feedback, and its later sections mark further constructs as Python moves. Start with the warm-up notebook in [`start-here/`](start-here/README.md) if you have never programmed.

## How to practise

Read the Python step of the lecture first, then run the same step in the notebook. Change one thing at a time in a working cell and predict the result before running it. Print the shape and the type of any object that surprises you. When an error appears, read the last line of the message first: It names the problem, and the lines above show where it happened. Keep a personal file of small snippets that worked, grouped by task: loading data, plotting, fitting a model, simulating a system.

## Beyond the course

The official Python tutorial is the reference for the language, and the documentation of NumPy, pandas, scikit-learn and PyTorch contains tutorials that follow the same order as the course.
