# The Python path

The course teaches Python step by step alongside the engineering content. Every week has a Python step at the start of its Colab notebook: It explains one group of fundamentals with the week's own example, places every snippet in a cell that runs it, and closes with a quick check and short exercises with immediate feedback. The printable lecture notes contain each step with the outputs of its code, and later sections of the notebooks mark further constructs as Python moves. Students who have never programmed start with the warm-up notebook in [`start-here/`](start-here/README.md).

The notebook links open each notebook at its Python step. Run the setup cell just above the step first, since the exercises use its `check` function. If the setup has not run in the current session, the first code cell of the step stops with a message.

## How to practise

Work through the Python step of each week at the start of its notebook, reading every explanation before running the cell below it. Change one thing at a time in a working cell and predict the result before running it. Print the shape and the type of any object that surprises you. When an error appears, read the last line of the message first: It names the problem, and the lines above show where it happened. Keep a personal file of small snippets that worked, grouped by task: loading data, plotting, fitting a model, simulating a system.

## Beyond the course

The official Python tutorial is the reference for the language, and the documentation of NumPy, pandas, scikit-learn and PyTorch contains tutorials that follow the same order as the course.
