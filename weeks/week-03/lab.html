Artificial Intelligence Applications in Engineering (MUH-920), week 3 of 14: interactive lab

Rule-based reasoning lab: Soil classification and pump diagnosis

Prof. Dr. Utku Kose, Süleyman Demirel University

Course homeLecture pageColab notebookPDF notes

Part A classifies a soil with the Unified Soil Classification System from grain-size and plasticity values set with sliders, and prints the reasoning path rule by rule next to the plasticity chart [1, 2]. Part B is a diagnostic expert system for a centrifugal pump with certainty factors: Symptoms are selected with a confidence, rules fire forward, evidence combines as in MYCIN, and every conclusion can be asked how it was reached [3].

Part A: USCS classification with an explanation

    Part B: Pump diagnosis with certainty factors

    Set a certainty for each observation (0 means not observed). Conclusions and their combined certainty update immediately. Select a conclusion to see how it was reached.

    ConclusionCertaintyRecommended action

    Six questions with instant feedback. Rate your confidence before checking each answer.

    Answers are saved in this browser only. The export creates a Markdown learning log for your portfolio.
