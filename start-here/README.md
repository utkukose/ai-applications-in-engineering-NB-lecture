This optional notebook is for students who have never programmed. In about two hours it introduces Google Colab, variables, f-strings, lists, loops, conditions, functions, dictionaries, a first plot and a first NumPy array, all with small engineering calculations: stresses in bars, loads on floors and the deflection of a cantilever. Exercises give immediate feedback, and reference solutions sit in collapsed cells.

To open it, click the Colab badge. Colab runs in the browser and needs only a Google account; nothing has to be installed. After the warm-up, continue with [Week 1](../weeks/week-01/README.md). The page [PYTHON_PATH.md](../PYTHON_PATH.md) lists which Python construct each later week introduces.
